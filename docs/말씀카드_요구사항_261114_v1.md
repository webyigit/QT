# 하루하루 말씀카드 — 요구사항 정의 (v1, 2026-11-14)

## 1. 목적
매일 한 구절의 성경 말씀을 타로카드처럼 "한 장 펼쳐 보는" 경험으로 전하고, 카드 뒷면에 묵상을 적어 친구와 나누는 모바일 웹앱(PWA[^1]).

## 2. 콘셉트 원칙
- 타로에서 빌리는 것: 세로로 긴 카드 비율, 금박 테두리, 앞·뒷면 뒤집기, 펼쳐진 카드 배열.
- 쓰지 않는 것: 별자리·수정구·달 위상·로마숫자 아르카나·운세 문구("오늘의 운", "행운")·무작위 뽑기.
  → 카드는 **날짜에 고정**된 말씀이며, 사용자가 고르지 않는다(점술 오해 차단).
- 분위기: 상아색 종이, 예배당 아치 창 안의 선화(線畫) 일러스트, 위에서 내려오는 빛, 잔잔한 빛 입자.

## 3. 사용자
- 주 사용자: 매일 QT(경건의 시간)를 하는 성도, 모바일 사용.
- 보조 사용자: 소그룹·셀 친구(묵상 공유 대상).

## 4. 기능 목록 및 우선순위
| ID | 기능 | 우선순위 | 비고 |
|---|---|---|---|
| F1 | 오늘 카드(중앙) + 어제(좌)·내일(우) 3D 원형 배치 | 필수 | 스와이프 시 원을 그리며 회전 |
| F2 | 중앙 카드 위아래 부유 애니메이션 | 필수 | 동작 줄이기 설정 시 정지 |
| F3 | 카드 탭 → 뒤집기, 뒷면에 묵상 작성·자동 저장 | 필수 | 날짜별 저장 |
| F4 | 앞면 말씀별 일러스트 | 필수 | 주제 25종 SVG 선화 |
| F5 | 읽음 표시(하트) + 읽은 카드 수(인스타식 하트 아래 숫자) | 필수 | |
| F6 | 년/월/일 검색 → 해당 날짜 카드로 이동 | 필수 | 달력에 읽음 점 표시 |
| F7 | 카드 이미지 저장(PNG) | 필수 | |
| F8 | 공유(Web Share, 미지원 시 링크 복사) + 공유 수 표시 | 필수 | 서버 연결 시 전체 공유 수 |
| F9 | 다크/라이트 모드 전환 | 필수 | 시스템 설정 기본 |
| F10 | 친구 맺기(친구 코드) | 필수 | 백엔드 필요 |
| F11 | 카드 뒷면에 친구들 묵상 함께 보기 | 필수 | 백엔드 필요, 친구 공개 선택 |
| F12 | 홈 화면 설치·오프라인 | 필수 | 서비스워커 |
| F13 | 미래 카드는 덮인 상태로 표시 | 권장 | "그날 열립니다" |

## 5. 데이터
- 본문: 개역한글판(1961, 대한성서공회). 저작권 보호기간 만료 본문으로 위키문헌에 공개 수록. [확인 필요: 상업적 배포 시 대한성서공회 공식 확인 권장]
- 데이터 출처: npm 패키지 `@scoynim/bible` 0.1.1 의 한국어 본문(개역한글 표기 "쉴만한 물 가으로" 등으로 판본 확인).
- 구절: 244개 엄선, 날짜 순번으로 순환(같은 날짜엔 항상 같은 카드).

## 6. 비기능
- 모바일 우선(360px~), 터치 44px 이상, WCAG 2.1 AA 대비.
- 개인정보 최소 수집: 닉네임만. 이메일·실명 불필요(익명 로그인).
- 키·비밀값은 저장소에 커밋하지 않음(GitHub Actions 시크릿으로 배포 시 주입).

[^1]: PWA(Progressive Web App): 웹사이트를 홈 화면에 설치해 앱처럼 쓰는 방식. 앱스토어 등록 없이 배포 가능.
