# 하루하루 말씀카드 — 화면 설계 (v1, 2026-11-14)

## 화면 목록
| 화면 | 설명 |
|---|---|
| S1 메인 | 상단바(로고·달력·친구·테마) / 3D 카드 링 / 하단 액션바(하트·공유·저장) |
| S2 카드 뒷면 | 내 묵상 입력 · 친구 공개 토글 · 친구 묵상 목록 |
| S3 날짜 찾기 | 년·월 선택 + 월 달력(읽은 날 점), 날짜 탭 → 해당 카드 |
| S4 친구 | 내 닉네임·친구 코드, 코드로 친구 추가, 받은 요청 수락, 친구 목록 |
| S5 정보 | 본문 출처·저작권, 개인정보 안내 |

## 흐름
```
앱 실행 → S1(오늘 카드 중앙)
  ├ 좌/우 스와이프 → 어제/내일 카드가 원을 그리며 중앙으로
  ├ 중앙 카드 탭 → 뒤집기 → S2 → 다시 탭(앞면 보기 버튼) → S1
  ├ ♡ 탭 → 읽음 표시, 하트 아래 숫자 = 읽은 카드 수
  ├ 공유 → 시스템 공유창 / 링크 복사, 아래 숫자 = 공유 수
  ├ 저장 → 카드 PNG 다운로드
  ├ 달력 → S3 → 날짜 선택 → S1(해당 날짜 중앙)
  └ 친구 → S4
```
