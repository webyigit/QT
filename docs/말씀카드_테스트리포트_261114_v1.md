# 하루하루 말씀카드 — 테스터 검증 리포트 (v1, 2026-11-14)

검증 방식: 테스터 서브에이전트 4명 병렬(기능·사용성·접근성/모바일·보안) → 치명·중요 수정 → 자동 회귀 테스트(Playwright 16항목 + axe-core) 재검증.
환경: Chromium(모바일 에뮬레이션: iPhone SE 320px·iPhone 13·Pixel 7·360×640·가로 844×390), 로컬 PostgreSQL 16으로 Supabase 권한 재현. Safari/iOS는 코드 검토로 판단 [확인 필요: 실기기 확인].

## 주요 수정 내역
**치명**
- 좁은 화면(320~375px)에서 상단 버튼·창이 화면 밖으로 넘침 → 좁은 화면에선 "말씀카드"로 줄이고 창 폭 100vw 제한
- 다크 모드에서 "끊기·거절·지우기" 버튼 글자 안 보임(대비 1.03:1) → 셀렉터 수정
- 가로·확대 시 카드가 84px까지 작아짐 → 카드 최소 190px, 본문 최소 13px, 가로 고정 해제
- 숨겨진 카드 뒷면 입력칸이 Tab으로 잡힘 → inert 처리

**중요**
- 회전 중 탭 시 카드가 기울어진 채 멈추고 엉뚱한 날짜가 읽음 처리 → 회전 완료 후 처리
- 먼 날짜 이동 중 "오늘로" 무시 / 화살표 연타 시 1칸만 이동 → 애니메이션 목표 기준으로 계산
- 기록 지우기 후 테마·친구 데이터 잔존 → 저장소 초기화 수정, 서버 연결 시 계정·서버 기록까지 삭제(delete_my_account)
- 연말·월말 달력 선택값 오류 → "내일"까지 반영, 이전/다음 달 버튼 추가
- 긴 구절 글씨 8~9px → 그림 단계 축소 후 최소 13px, 그래도 넘치면 카드 안 스크롤
- 하트·숫자 의미 불명 → "읽은 카드 / 공유 / 저장" 라벨 표시
- 뒷면이 비좁음 → 뒷면 확대·스크롤, 말씀 탭하면 펼침, 옆 카드 숨김
- 금색 글자 대비 3.3:1 → 글자용 금색(#7a5a20, 약 5.5:1) 분리, 입력 테두리·포커스 링 대비 강화
- iOS 공유 실패 가능(사용자 동작 권한 만료) → 카드 이미지를 미리 생성, 실패 시 텍스트 공유→복사 순으로 대체
- iOS 이미지 저장 → 공유 시트의 "이미지 저장" 경로 안내
- 친구 코드 무차별 대입 무제한 → 성공·실패 포함 하루 20회 제한
- 공유 수 부풀리기·DB 남용 → 날짜 범위 제한, 공유 수는 "공유한 사람 수"(중복 제거), 사용자당 하루 30회·묵상 1,500개 제한
- 묵상이 기본 친구 공개 → 기본 비공개(직접 켜야 공개)

**기타**: CDN 의존 제거(supabase-js를 저장소에 포함, CSP `script-src 'self'`), 덮인 내일 카드 남색→상아색, 알림을 화면 위쪽으로, 자정 넘김 1분마다 확인, 잘못된 날짜 링크 무시, 내부 함수 실행 권한 회수.
